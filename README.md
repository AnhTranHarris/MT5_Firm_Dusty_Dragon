# Dusty Dragon

Dusty Dragon is a PC-first, evidence-driven proprietary trading firm platform for MetaTrader 5. The system is designed around independent trading desks, strict capital/risk governance, reproducible research, broker-neutral data contracts, and replaceable open-source contractors.

## Constitutional principles

- Dusty Dragon Core is sovereign; contractors never own capital authority.
- Each desk owns an independent capital account. Capital is never shared between desks.
- Survival and risk compliance outrank growth targets.
- Growth targets are objectives, never permission to force trades or increase risk.
- Evidence and execution are separate domains. Only Dusty Core may create an `ApprovedOrder`.
- Hardware changes concurrency, never qualification rigor.
- Layer 0 demo desks are the permanent research/challenge laboratory.
- Institutional knowledge persists; financial privileges must be earned repeatedly.
- Human CEO authorization is required for brokerage-account creation, capitalization, and constitutional policy changes.
